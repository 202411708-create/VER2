# 🚀 시간탐정 빠른 시작 가이드

## 설치 및 실행 (5분)

### 1단계: 프로젝트 설치
```bash
cd time-detective
npm install
```

### 2단계: 개발 서버 실행
```bash
npm run dev
```

### 3단계: 브라우저 접속
- 자동으로 브라우저가 열립니다
- 또는 http://localhost:5173 접속

---

## 프로그램 사용법

### 학생 사용 시나리오

#### 1️⃣ 시작 (1분)
- "시작하기" 버튼 클릭
- 안내 메시지 읽기

#### 2️⃣ Module 1: 시간여행 타임라인 (20분)

**목표**: 어제 하루를 타임라인에 기록하기

**방법**:
1. 활동 버튼 선택 (수면 😴, 공부 📚, SNS 📱 등)
2. 타임라인의 시간대를 클릭하여 활동 추가
3. 활동 블록을 클릭하면 삭제 가능
4. 활동 목록에서 시간 조정 가능
5. "결과 보기" 버튼으로 분석 확인
6. 원형 차트와 통계 확인
7. "다음 단계로" 버튼 클릭

**팁**:
- 정확하지 않아도 괜찮아요
- 대략적인 시간으로 기록하세요
- 실수했다면 언제든 삭제하고 다시 추가할 수 있어요

#### 3️⃣ Module 2: 시간도둑 잡기 (20분)

**목표**: 시간을 낭비하게 만드는 행동 찾기

**방법**:
1. 왼쪽의 시간도둑 카드를 읽어보세요
2. 공감되는 정도에 따라 분류하세요:
   - 🔴 빨간 상자: 나한테 정말 해당돼요 (시간을 많이 빼앗김)
   - 🟡 노란 상자: 가끔 그래요
   - 🟢 초록 상자: 별로 안 그래요
3. 카드를 드래그해서 상자에 넣으세요
4. 잘못 넣었다면 × 버튼으로 빼낼 수 있어요
5. 10장을 모두 분류하면 "결과 보기" 버튼이 나타나요
6. 결과 확인 후 "다음 단계로" 클릭

**팁**:
- 솔직하게 생각해보세요
- 정답은 없어요
- 친구와 다를 수 있어요

#### 4️⃣ 종합 결과 (5분)

**확인 사항**:
- 나의 시간 사용 패턴 (원형 차트)
- 시간도둑 TOP 3
- 되찾을 수 있는 시간
- 성찰 메시지

**액션**:
- 🖨️ 인쇄하기: 종이로 출력
- 💾 데이터 저장: 나중에 다시 보기
- 🔄 처음부터 다시: 모든 내용 초기화

## 상담자 가이드


   - 충분한 시간 확보 (50분+)

### 세션 진행

#### 도입 (5분)
- "오늘은 시간탐정이 되어 나의 시간을 찾아볼 거예요"
- 프로그램 소개 화면 함께 읽기
- 정답이 없다는 점 강조
- 솔직하게 기록하도록 격려

#### Module 1 진행 (20분)
- 학생이 직접 조작하도록 격려
- 막히는 부분만 도움
- "어제는 어떤 하루였어요?" 질문
- 활동 추가 방법 시연 (필요시)
- 결과 해석은 강요하지 않기

**개입 예시**:
- "여기 공부 버튼을 누르고, 공부한 시간대를 클릭해보세요"
- "삭제하고 싶으면 블록을 클릭하면 돼요"
- "대충 이 정도 시간이었다고 생각하면 그렇게 하면 돼요"

#### Module 2 진행 (20분)
- 카드를 천천히 읽도록 안내
- "이건 나한테 해당되나?" 질문
- 분류에 정답 없음 재강조
- 학생의 선택 존중

**개입 예시**:
- "이 카드 읽어봤어요? 어떤 것 같아요?"
- "이게 나한테 많이 일어나나요, 가끔 일어나나요?"
- "잘못 넣었다고 생각하면 다시 빼도 돼요"

#### 결과 정리 (5분)
- 결과 화면 함께 보기
- "어떤 걸 발견했어요?" 질문
- 성찰 메시지 함께 읽기
- 데이터 저장 권장

## 자주 묻는 질문 (FAQ)

### Q1. 데이터가 저장되나요?
**A**: 네, 자동으로 저장됩니다. 같은 브라우저에서 다시 접속하면 이어서 할 수 있어요.

### Q2. 잘못 입력했어요!
**A**: 걱정하지 마세요!
- 타임라인: 블록을 클릭하면 삭제돼요
- 시간도둑: × 버튼을 누르면 다시 빼낼 수 있어요

### Q3. 정확한 시간을 모르겠어요
**A**: 괜찮아요! 대략적으로 기억나는 대로 하면 됩니다. 정확한 시간보다 패턴을 파악하는 게 중요해요.

### Q4. 활동이 겹치는 시간이 있어요
**A**: 그럴 수 있어요! 더 오래 한 활동이나 기억에 남는 활동을 선택하세요.

### Q5. 중간에 멈춰도 되나요?
**A**: 네! 자동으로 저장되니까 나중에 이어서 할 수 있어요.

### Q6. 인쇄나 저장은 어떻게 하나요?
**A**: 결과 화면에서:
- 🖨️ 인쇄하기: 종이로 출력
- 💾 데이터 저장: JSON 파일로 저장

### Q7. 모바일에서도 되나요?
**A**: 네! 스마트폰, 태블릿 모두 사용 가능합니다. 터치로 드래그할 수 있어요.

### Q8. 처음부터 다시 하고 싶어요
**A**: 오른쪽 위 "처음부터 다시" 버튼을 클릭하세요. 모든 데이터가 삭제되니 주의하세요!

## 트러블슈팅

### 화면이 안 보여요
1. 브라우저를 새로고침하세요 (F5)
2. npm run dev 명령어를 다시 실행하세요
3. 다른 브라우저로 시도하세요 (Chrome, Edge, Safari 권장)

### 드래그가 안 돼요
1. 마우스/터치가 작동하는지 확인하세요
2. 카드를 클릭한 상태로 상자까지 끌어오세요
3. 모바일: 길게 눌러서 드래그하세요

### 데이터가 사라졌어요
1. 같은 브라우저를 사용했는지 확인하세요
2. 시크릿 모드를 사용하지 않았는지 확인하세요
3. 브라우저 데이터를 삭제하지 않았는지 확인하세요
